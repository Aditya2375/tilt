tilt

A keyboard-driven tiling window manager for X11, in C. This page shows the real WM running.

Why a recording instead of an in-browser run?

tilt manages windows for a real X11 server — it grabs keyboard shortcuts, reparents client windows and arranges them on screen. A browser tab has no X server to manage, so the honest way to show it here is the actual binary at work: this capture is build/tilt running under Xvfb, driven through real XTEST keystrokes by the same harness (tests/xpress) the CI integration suite uses, recorded with ffmpeg.

What the clip shows

0:00–0:07Three windows open and tile automatically (master + stack), focus border follows the mouse
0:07–0:12Alt+2 switches to empty workspace 2, Alt+1 switches back
0:12–0:17A transient dialog opens floating and centered, then closes
0:17–0:21Alt+L grows the master width, Alt+Shift+Q closes windows, Alt+Q quits

Run it yourself

On any Linux box with X11: make, then Xephyr :1 &, DISPLAY=:1 ./build/tilt and open a few clients with DISPLAY=:1 xterm. The full test suite (make check) runs the same scripted session headlessly.
